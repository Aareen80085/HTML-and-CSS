HOW TO PLAY

🎯 Goal

A buggy code snippet is given to all players. Crewmates must find and fix the bug. The Impostor must secretly sabotage the code without getting caught.

🟢 As Crewmate

  • 1. Read the buggy code in the editor
  • 2. Edit the code to fix the bug
  • 3. Click Submit Fix to check your answer
  • 4. Watch for code changes you didn't make
  • 5. Call Emergency Meeting to vote out suspects

🔴 As Impostor

  • 1. Blend in — pretend to fix the code
  • 2. Click Sabotage to mutate the code
  • 3. 5 sabotage types: swap operators, flip math, off-by-one, comment return, rename vars
  • 4. Get 3 sabotages through to win!
  • 5. Survive the vote — deflect suspicion in chat
